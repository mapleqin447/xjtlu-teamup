多页面静态网站：**课程作业 + 学科竞赛** 双板块组队平台。
全站采用**平面设计（graphic design）**语言，参考《明日方舟》的视觉体系。

## 设计说明

### 配色：全部来自组标

    --ink    #0a0f24   近黑藏青   ← nox-logo-on-light.svg
    --accent #8c6a1f   铜金       ← nox-logo-on-light.svg
    --paper  #f2f1ed   浅暖白底

这套「深藏青 + 金」和《明日方舟 x 女神异闻录3 Reload》联动活动
「月行水上」的深藏青 + 明黄是同一路数，所以它既符合组标，也符合方舟的味道。

想换成方舟原版那种青蓝（cyan），只需要把 `--accent` 改成比如 `#00b8d4`。

### 参考的六条平面设计原则

| # | 原则 | 在代码里怎么体现 |
| --- | --- | --- |
| 1 | 黑白灰为主、低饱和，一点亮色点关键信息（机能风） | 全站只有 `--ink` / `--paper` / 一个 `--accent` |
| 2 | 大标题最重字重 + 负字距；小标签等宽字、大写字距拉满 | `.gd-title{font-weight:900;letter-spacing:-.042em}`、`.gd-meta` |
| 3 | 半调网点（halftone） | `.gd-halftone`、`.gd-dots`、`.cta::after`，用 `radial-gradient` 点阵 + `mask` 做出渐隐 |
| 4 | 硬边：直角、粗黑分割线，不用圆角与投影 | 全站 `border-radius:0`，分割线用 2px/3px 实线 |
| 5 | 技术性装饰：坐标刻度、对位符、条形码、编号 | `.gd-rule`（刻度尺）、`.gd-barcode`（三层竖线叠出条码）、`.gd-specimen` |
| 6 | 极高层级对比 | 要么近黑块白字，要么白底近黑字，中间灰很少 |

### 滚动渐入：怎么做才安全

「滚动渐入」的隐藏状态写在 CSS 里，但**只在 `<html>` 带 `js` 类时才生效**：

    .js :where(.gd-row, .reason, .board, ...){
      opacity:0;
      transform:translateY(26px);
      transition:opacity .9s cubic-bezier(.22,1,.36,1), transform .9s cubic-bezier(.22,1,.36,1);
    }

而 `js` 类由每个页面 `<head>` 里这一行加进去：

    <script>document.documentElement.classList.add("js");</script>

这样万一脚本没加载成功，内容默认就是可见的，**不会白屏**。
这是做滚动动画的标准套路，可以直接搬到别的项目用。

同一组里的元素会依次延迟 90ms 出现（阶梯感），逻辑在 `script.js` 里。

## 登录页（login.html）

一左一右的分栏卡片：左边是深色图形面板（组标的**浅色版**正好放这里），
右边是表单。窄屏（≤900px）自动变成上下堆叠。

页面里做了这些：

- 密码「显示 / 隐藏」切换
- 「记住我」用 CSS 自绘勾选框（`appearance:none` 去掉原生样式，再用伪元素画勾）
- 提交按钮、以及「使用学校统一认证登录」按钮，都会给出提示
- **这是原型、没有后端**，所以提交会被 JS 拦下来（`event.preventDefault()`）；
  如果是空值还会把输入框描边标红。以后接了后端，把 `script.js` 第 7 节删掉即可。

导航里新增的「登录」文字入口写在每个页面的 `<header>` 里，手机菜单和页脚也有。

## 注册页（register.html）

一张长表单（01~05 编号分段）+ 右侧一块**实时档案预览** —— 你左边填什么，
右边那张「队友会看到的卡片」就实时长成什么样。

- 头像用 `URL.createObjectURL(file)` 做**本地预览，不上传任何服务器**（原型）
- 没上传头像时，预览里自动用名字的**第一个字**当占位
- 擅长方向是标签多选，**最多 6 个**，超出会提示并自动取消刚点的那个
- 自我介绍带实时字数统计（`maxlength="120"`）
- 提交做校验：账号、密码长度、名字、至少一个方向、同意条款，缺哪项就列出来
- 窄屏（≤1000px）时预览会挪到表单**上方**

联动逻辑在 `script.js` 第 8 节，全是原生事件 + 改 `textContent`，没有框架。
想验证联动是否正常，可以在 Console 里改 `nickname.value` 然后
`nickname.dispatchEvent(new Event("input"))`，右侧会立刻跟着变。

## 组队帖列表页（listings.html）

**一条招募帖的字段**（后面的详情页、发布表单都跟着它走）：

    板块 board      课程作业 / 学科竞赛
    代码 code       INT202、MCM/ICM …
    标题 + 描述      一句话说清要干什么
    需要的技能       编程 / 建模 / 数据分析 …
    期望投入时间     工作日晚间 / 周末白天 …
    发布者          名字 + 专业 + 年级 + 组队信用分
    人数            缺 2 人 · 共 4 人
    发布时间、是否还有空位

**交互**：板块切换、搜索、技能标签、时间标签、只看有空位、重置。
实现方式全部是「显示 / 隐藏」——11 条帖子是**写死在 HTML 里**的。

这样安排是有意的：**脚本不跑时，帖子照样全都在**，只是不能筛。
（如果帖子改成 JS 渲染，脚本一挂页面就空了。）

筛选规则在 `script.js` 第 9 节：**同一行多选是「满足任一」(OR)，不同行之间是「同时满足」(AND)**。
帖子靠 `data-board` / `data-skills` / `data-times` / `data-open` / `data-keyword`
这几个属性参与筛选，加新帖子照抄一条改内容即可。

另外，登录页和注册页现在提交成功后会跳到这一页，
把「登录之后没地方去」这个断点补上了（没有后端，是直接跳转演示）。

## 演示数据：纯前端的「记忆」

没有服务器，但演示不该「填完就没」。所以用 `localStorage` 做了一层本地记忆：

| 动作 | 效果 |
| --- | --- |
| 注册提交 | 档案（名字 / 专业 / 年级 / 技能 / 时间 / 自我介绍 / 头像）存进本地 → 跳到**个人主页**，显示你自己的信息 |
| 发布招募帖 | 帖子存进本地 → 跳到**组队帖列表**，**排在最前面**并带「我发布的」标记，也正常参与筛选 |
| 登录 | 标记登录状态 → 导航右上角从「登录」变成**头像 + 名字** |
| 重置 | 导航上的「重置演示」按钮清空数据并刷新 |

**四个实现要点**（都是坑）：

1. **读写全部包 `try/catch`** —— 部分手机浏览器（Safari 关 Cookie、App 内置浏览器）一读 localStorage 就抛异常，裸调会让**整个脚本挂掉**、所有交互失效。
2. **头像必须存 dataURL**：原来的 `createObjectURL` 一刷新就失效。现在用 `FileReader` 读成 dataURL，再用 canvas **缩到 240×240 居中裁切**（顺便兑现了界面上「会按正方形裁切」的承诺），一张图约 20KB，不会撑爆 localStorage 的 5MB。
3. **用户输入先转义再拼 HTML**（`esc()`）—— 名字里带个 `<` 就能破坏页面结构。
4. **没有数据时页面保持原样**：个人主页显示示例档案并加一句说明，导航照常显示「登录」。所以脚本挂了、或者第一次打开，页面都不会空。

数据存在**你双击打开的那个浏览器**里（`file://` 协议实测可用），换浏览器就没了 —— 这本来就是演示用的，不是真的账号系统。
